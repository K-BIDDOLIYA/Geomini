# Geomini

A lightweight 3D shape viewer built with HTML, CSS, and JavaScript.

### Features
- View cubes, spheres, cones, cylinders, and pyramids.
- Rotate shapes by dragging.
- Change shape colors.
- Reset the view anytime.
- Works on desktop and mobile.

### Built With
- HTML
- CSS 3D Transforms
- JavaScript

### Run
Open `index.html` in your browser and explore 3D shapes!

Made for the Shrink project.
